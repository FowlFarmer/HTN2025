# Examples Directory

## Overview
This directory contains sample images, test cases, and output examples from the painting vectorization pipeline.

## Sample Images

### `monet.jpeg`
- **Type**: Impressionist painting reproduction
- **Dimensions**: 600×482 pixels
- **Artist**: Claude Monet style
- **Use case**: Primary test image for pipeline development
- **Features**:
  - Rich color palette
  - Varied brush strokes
  - Multiple distinct visual elements (sky, water, structures)
  - Good contrast for segmentation

## Usage Examples

### Testing Step 1 (Preprocessing)
```python
from step1_preprocessing.image_preprocessing import preprocess_image

# Test with sample image
processed_img, scale_factor, original_dims = preprocess_image("examples/monet.jpeg")

print(f"Original: {original_dims}")
print(f"Scale factor: {scale_factor}")
print(f"Processed shape: {processed_img.shape}")
```

### Testing Step 2 (Segmentation)
```python
from step2_segmentation.segmentation import segment_painting

# Full pipeline test
masks, scores, processed_img = segment_painting("examples/monet.jpeg")

print(f"Generated {len(masks)} masks")
for i, score in enumerate(scores):
    print(f"Mask {i}: salience={score['salience']:.3f}")
```

### End-to-End Pipeline Test
```python
import sys
sys.path.append('painting_vectorization')

from step1_preprocessing.image_preprocessing import preprocess_image
from step2_segmentation.segmentation import segment_painting

# Step 1: Preprocess
processed_img, scale, dims = preprocess_image("examples/monet.jpeg")
print(f"✓ Preprocessing complete: {dims} -> {processed_img.shape[:2]}")

# Step 2: Segment
masks, scores, _ = segment_painting("examples/monet.jpeg")
print(f"✓ Segmentation complete: {len(masks)} masks generated")

# Step 3: Ready for stroke extraction (future implementation)
print("✓ Ready for stroke extraction pipeline")
```

## Expected Results

### Monet.jpeg Processing
- **Step 1 Output**: 600×482×3 float32 array, scale=1.0
- **Step 2 Output**: ~5 meaningful masks with salience scores
- **Processing time**: ~30-60 seconds total (CPU)

### Quality Metrics
- **Segmentation quality**: Masks should capture distinct visual elements
- **Mask coverage**: Combined masks should cover 80-95% of image
- **Overlap**: Minimal overlap after merging (IoU < 0.6)

## Adding New Test Images

### Recommended Image Properties
- **Size**: 500-2000 pixels (any dimension)
- **Format**: JPEG, PNG, or other common formats
- **Content**: Paintings with distinct visual elements
- **Quality**: High resolution, good contrast

### Testing Workflow
1. Add image to `examples/` directory
2. Run preprocessing test
3. Run segmentation test
4. Verify output quality
5. Document results in this README

### Image Categories for Testing
- **Impressionist**: Loose brush strokes, color mixing
- **Realist**: Sharp edges, detailed structures
- **Abstract**: Geometric shapes, color blocks
- **Landscape**: Natural elements, varying textures
- **Portrait**: Faces, clothing, backgrounds

```python
assert processed_img.shape[2] == 3  # RGB

```

### Segmentation Validation
```python
assert 3 <= len(masks) <= 6  # Target mask count
for mask in masks:
    area_ratio = np.sum(mask) / (mask.shape[0] * mask.shape[1])

```

## Troubleshooting

### Common Issues
- **File not found**: Check image path relative to script location
- **Out of memory**: Use smaller images or GPU acceleration
- **Poor segmentation**: Try different SAM model variants
- **Missing dependencies**: Install requirements from main README
